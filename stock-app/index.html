    交易紀錄

    如何從國泰證券／集保帶入持股？
    國泰證券與集保「e手掌握」目前未提供第三方讀取個人庫存的公開 API，所以採「匯出 → 匯入」： 國泰證券網頁版／電子交易平台的「對帳單／成交明細」或「庫存查詢」可下載 CSV／Excel（Excel 請另存為 CSV）； 本 App 會自動辨識「股票代號、股數／張數、均價／成交價、買賣別、日期、手續費、交易稅」等欄位，並支援 Big5 編碼與民國年。 有「買賣別」欄位視為成交明細，沒有則視為庫存快照。

    新增規則

    規則清單

    手機即時推播（App 關閉時也能收到）

    瀏覽器通知只在 App 開著（或背景分頁）時運作。要在 App 關閉時也收到，請使用 repo 內附的 GitHub Actions 推播服務：盤中每 5 分鐘用證交所即時行情檢查規則，並透過 ntfy（免費、免註冊，手機裝 ntfy App 訂閱主題即可）或 Telegram Bot 推播到手機。
    步驟：① 下方按「匯出推播設定」得到 alerts.json → ② 放到 repo 的 stock-app/notifier/alerts.json → ③ 在 GitHub repo Settings → Secrets 設定 NTFY_TOPIC（或 TELEGRAM_BOT_TOKEN＋TELEGRAM_CHAT_ID）。詳見 stock-app/README.md。
